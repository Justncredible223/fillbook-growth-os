## Real bugs found and fixed this session (all now covered by tests where applicable)

1. RLS was disabled on every table since Phase 1 — anon key could've read/
   written everything. Fixed (migration 0005).
2. First Vercel deploy crashed every function (`ERR_MODULE_NOT_FOUND`) —
   ESM relative imports need explicit `.js` extensions under Node's
   loader. Fixed by deploying with CommonJS instead.
3. Vercel's default "Vercel Authentication" protection blocked the
   Android app entirely — fixed via a Protection Bypass secret (see above).
4. Pasted Supabase key had a literal newline in it, breaking the HTTP
   header — also was the wrong key format (`sb_secret_...` vs the classic
   `service_role` JWT this code expects). Fixed by using Supabase's
   "Legacy API keys" page.
5. Once the real key was finally read, `errorMessage()` bug: Supabase's
   error objects aren't always `instanceof Error`, so error messages were
   collapsing to `"[object Object]"`. Fixed, now unit tested.
